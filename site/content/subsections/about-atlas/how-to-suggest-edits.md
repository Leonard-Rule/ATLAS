## Suggest an Edit to Existing Code
id: suggest-code-edit
type: sop

Found an issue or improvement opportunity in one of our SAS code snippets? To suggest a code edit:

1. **Locate the snippet** — Find the code example you'd like to improve in the Code Examples section or any section containing SAS code
2. **Click "Suggest Edit"** — Look for the "Suggest Edit" button near the code block
3. **You will be taken to TFS** - Click 'main' to the left of the file name and new branch. Enter a branch name like 'initials_filename_edits'
4. **Make your changes** — Click edit and make the code edits, then save
5. **Go to the "Pull Requests" tab** — Click "New Pull Request" and select your branch. Add context and add the appropriate reviewers and then click "Create Pull Request"

## Report a Documentation Issue
id: report-issue
type: sop

Notice a typo, unclear explanation, or missing information in the reference material?

1. **Identify the issue** — Note the section and page where the issue appears
2. **Click "Report Issue"** — Use the flag icon or feedback button on the page
3. **Describe the problem** — Clearly state what's incorrect or missing
4. **Submit** — We will review and address it
